# Spotter Freight Rate Prediction — Solution

## What this does

Predicts trucking load rates ($/load) for Nov–Dec 2025 validation loads and a fixed
Lexington→Fort Wayne lane for every day of December 2025, using a HistGradientBoostingRegressor
trained on Jan–Oct 2025 data.

## Environment & Setup

Tested with **Python 3.14.2**.

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

## Data

The `data/` folder is not committed; place `train_test.csv`, `validation.csv`, and
`december_chart_inputs.csv` there before running.

## How to run

```bash
# 1. Fit and write submission files
python train_predict.py

# 2. Validate and generate the December chart
python score.py --predictions validation_predictions.csv --december-predictions december_predictions.csv
```
*(Note for Windows cmd: if splitting across lines, use `^` as line continuation rather than `\`)*

## Validation approach

Training data covers Jan–Oct 2025 (48,000 loads). Validation is Nov–Dec 2025 (12,000 loads),
a strict out-of-time split. Validation labels are not available and all error figures are
rolling-backtest estimates. Model selection used a rolling monthly backtest: train on all
clean months before the test month, evaluate on that month, Apr–Oct 2025.

A random split trains on rows from the same dates as the test rows (temporal leakage),
so its error is optimistic; the time split mirrors the real task.

## Key findings

- **~1.4% of training labels** (675/48,000) have rate-per-mile outside 1.2–4.0 $/mi.
  They are spread evenly over months and equipment types, consistent with data entry errors.
  They are excluded from training but left in the data files. ~1.4% of training labels
  look corrupted and probably exist in the hidden validation labels too, which would
  inflate squared-error metrics for any model.

- **quote_signal** was excluded. It mirrors the target (rate per mile) but with a sign
  that alternates by month and appears as noise (corr ≈ 0) in Nov–Dec. Using it causes
  large errors on months where the sign flips.

- **market_index** was excluded. It helped Apr–Jul but hurt Aug–Oct (test market lower
  than training market), and is not available in the December chart inputs file.

- **Weekday** is the only calendar feature kept. Holiday-gap and day-of-month features
  hurt out of time (overfitting to specific dates seen in training).

- **Geography encoding**: Integer city codes did not help on unseen cities (MAE 63.9
  vs 64.2 without geography), categoricals helped modestly (61.1), coordinates helped
  most (48.6). Chosen feature set: distance, weight, equipment dummies, weekday,
  pickup lat/lon, delivery lat/lon.

- **8 unseen pickup/delivery cities** appear in validation.csv but not in train_test.csv
  (Allentown, Charlotte, Chicago, Jackson, Knoxville, Laredo, Norfolk, San Diego),
  covering 1,447 of 12,000 validation rows (12.1%). All December cities are in training.
  Validation rows provide coordinates for all cities directly; for December, coordinates
  are looked up from training data.

## Models compared

Candidate models evaluated using rolling monthly backtest (Apr–Oct 2025, clean rows)
on the final feature set (`distance`, `weight`, `equipment`, `dow`, `pickup_lat`,
`pickup_lon`, `delivery_lat`, `delivery_lon`):

| Model | Mean MAE ($) | Std MAE ($) | Mean MAPE (%) | Months won vs HGB (of 7) |
|---|---|---|---|---|
| **HistGradientBoosting (HGB)** | **75.79** | 41.21 | **3.11%** | — |
| SVR (8k row cap) | 77.63 | 36.12 | 3.23% | 3 |
| Random Forest (100 trees) | 78.53 | 38.47 | 3.23% | 1 |
| Ridge Regression | 110.27 | 21.53 | 4.63% | 0 |
| Naive Median RPM | 195.77 | 13.32 | 9.29% | 0 |

HGB achieved the lowest overall mean MAE and mean MAPE while natively supporting missing
weights and scaling efficiently across folds.

## Expected error

All figures are out-of-time rolling backtest estimates on clean rows (rate-per-mile 1.2–4.0):

- **Monthly backtest range (Apr–Oct 2025)**: MAE $39.91 to $149.20 (MAPE 1.74% to 5.95%)
- **Apr–Oct 7-month mean**: MAE $75.79 (MAPE 3.11%)
- **Recent months mean (Sep–Oct 2025)**: MAE $42.22 (MAPE 1.81%)
- **Unseen-city simulation (held-out cities, Sep–Oct test)**: MAE $47.49 to $49.53 across
  5 random seeds (5-seed mean MAE $48.55, MAPE 1.92%)

## Limitations

- December market conditions are unknown; the model uses only structural (distance,
  weight, equipment, weekday, city coordinates) features, so it cannot respond to
  unobserved freight market shifts.
- The December predictions repeat by weekday (no date-level variation beyond day-of-week)
  because holiday effects are not modelled (holiday features hurt out of time) and market
  information is unavailable for December.
- Model and feature choices were compared on the same rolling folds, so the backtest
  figures are slightly optimistic and there is no untouched final holdout.
- Validation labels are not available, so actual performance on Nov–Dec cannot be
  directly measured.

## Assignment

Original assessment instructions from Spotter (`freight-rate-ml-assessment.pdf`):

1. Train and validate your model using `data/train_test.csv`.
2. Predict every load in `data/validation.csv`. Each load has a unique `load_id`.
3. Fill the matching `predicted_rate` values in `data/validation_predictions_template.csv` and save it as `validation_predictions.csv`.
4. Predict every row in `data/december_chart_inputs.csv` by filling its `predicted_rate` column.
5. Install the scorer requirements and run `score.py` to validate predictions and generate `scorer_results/candidate_december.png`.
